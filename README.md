# NetScope

用 Three.js 观测当前 Mac 的真实网络传输。Python 服务调用本机系统工具，页面和数据都留在本机，不连接云端，不生成演示流量。

## 启动

需要 macOS、Python 3.9+、Node.js 20+。首次运行：

```bash
cd /Users/byron/my-files/code/codex-net-show
npm install
npm start
```

打开 http://127.0.0.1:8765 。也可在 Finder 双击 `start.command`。终端按 Ctrl+C 停止。

端口占用时：

```bash
python3 -m netshow --port 8766
```

## 使用

- 选择网卡查看实际收发速率，默认使用系统默认出口；网卡选择影响指标与下一次抓包，连接表展示全机连接。
- 拖动或滚轮操作 3D 视角；点击节点、远端 IP 或连接行查看 Socket 流量与进程。
- 使用搜索、协议按钮和回环选项筛选。连接/数据包/进程页展示不同统计口径。
- 点击「开启数据包采集」先尝试当前权限；无权限后点击「系统授权抓包」，在 macOS 系统弹窗认证。也可以直接点击下方同名授权入口。
- 抓包运行时点击停止。停止后仍可查看已有数据；退出服务后释放所有记录。
- 点击数据包查看 IP、端口、TTL、TCP flags 和十六进制/ASCII 原始字节。
- 点击「探测此 IP 的链路」查询本地实际路由，并主动执行最多 12 跳的 traceroute。
- 「暂停显示」冻结当前视图，后台采样与抓包继续。

## 数据来源和范围

| 内容 | 实际来源 | 统计口径 |
| --- | --- | --- |
| 收发速率 | `netstat -ibn` | 所选单网卡字节计数的时间差值 |
| 连接与进程流量 | `nettop` | Socket / 进程累计计数和最近采样的差值 |
| 连接降级 | `lsof` | 进程和连接，速率显示为不可用 |
| 数据包 | `tcpdump` | 本次服务生命周期内累计观察的包与字节 |
| 本地 IP / 出口 | `ifconfig`、`route` | 系统实际地址和路由 |
| 跳点和延迟 | `traceroute` / `traceroute6` | 点击时主动探测的结果 |

系统采样每 2 秒一次，页面数据流每秒刷新。连接表最多返回 500 条，表格最多渲染 150 条，3D 展示筛选后最活跃的 40 个远端 IP。首次采样没有差值时速率显示 `—`；这与真实零值 `0 B/s` 不同。

Socket 累计流量、进程累计流量、网卡流量和抓包观察量有不同生命周期与层级，不能直接相加或认为必须相等。进程汇总包含该进程所有网卡。当前用户可见性受 macOS 系统工具权限限制。

每包采集前 256 字节，内存仅保留最新 600 包；列表显示最新 100 包。不保存 PCAP 文件，不提供导出。非 IP/ARP 包跳过且计入 skipped。抓包仅表示用户选择的接口上可观察到的流量，不意味着逐包无丢失；未读取到内核丢包统计时不虚构丢包率。

3D 连线是逻辑连接。流光由测得的 Socket 活动或新收到的包驱动，是活动提示而非逐包精确回放。只有 traceroute 面板展示实测中间跳点，未响应保持未知。代理/VPN 可隐藏原始终点或经过路径。

HTTPS/TLS/QUIC 正文一般加密，此工具不解密。根据端口提示的应用服务只是推测，不是协议识别结论。

默认使用单接口，避免 VPN 与物理网卡重复统计。「抓取所有接口」使用 macOS 的 `pktap,all -y RAW`，同一个包可能在多个接口被重复观察；这是观察数，不是去重包数。

## 权限和故障

网页服务始终使用当前普通用户，仅监听 `127.0.0.1`。系统授权只运行固定参数的 `tcpdump`，随后通过 `-Z` 降回原用户。网页写操作验证同源和随机会话令牌，不开启 CORS。

授权启动时为后台任务重定向 stdin/stdout/stderr，不依赖 `nohup`。macOS 的无控制台授权环境可能使 `nohup` 报 `can't detach from console`，本项目已移除此调用。

若系统统计提示 `Operation not permitted` 或 `NStatManagerCreate failed`，请从普通终端执行 `npm start`；受限沙箱可能禁止系统计数器。抓包权限由系统认证提供，不能在聊天中代填密码。授权失败/取消会显示系统错误，可重试。

修改 Python 后需要重启服务；更新页面代码后刷新浏览器。重启后若页面仍持有旧令牌，也请刷新。

浏览器需要 WebGL 2。无法启动 Three.js 时仍保留连接表、速率与数据包功能，可在浏览器开启硬件加速。
